★ Sistema Premium Cargo Stats

Versão 1.0 — Junho/2026 — Planejamento técnico

1. Objetivo

Criar um sistema de assinatura premium com 3 planos (Doador, Gold, VIP) integrado ao Mercado Pago como gateway de pagamento, gerando receita recorrente para o projeto e oferecendo benefícios reais aos apoiadores.

5. Fluxo de Pagamento

USUÁRIO            SERVIDOR                MERCADO PAGO
 │             │                 │
 └ Acessa /premium ────────────→  │           │
 │ ←────── Lista 3 planos ─────  │           │
 │             │           │
 └ Clica "Assinar" ───────────→  │           │
 │             └ POST /api/premium/criar-pagamento ─→  │
 │             │ ←── Link Checkout / QR PIX ──  │
 │ ←────── Link / QR Code PIX ─────  │           │
 │             │           │
 └ Usuário paga ───────────────────────────────────→  │
 │             │ ←─────── WEBHOOK ─────── └
 │             │ POST /api/webhooks/mercadopago         │
 │             ├ Valida assinatura do webhook         │
 │             ├ Insere em `pagamentos`         │
 │             ├ premium_ate = now + 30 dias         │
 │             └ Desbloqueia Troféu Doador         │
 │             │           │
 └ Verifica status ───────────→  │           │
 │ ←── "Premium até dd/mm" ─────  │           │

11. Dependências Técnicas

Novo pacote npm:
npm install mercadopago@^2.0.0
Configuração necessária (.env):
MERCADO_PAGO_ACCESS_TOKEN=seu_token_aqui
MERCADO_PAGO_PUBLIC_KEY=sua_public_key
MERCADO_PAGO_WEBHOOK_SECRET=seu_segredo
MERCADO_PAGO_WEBHOOK_URL=https://seudominio.com/api/webhooks/mercadopago
Conta Mercado Pago necessária:
  1. Criar aplicação no Mercado Pago Developers
  2. Gerar Access Token (produção)
  3. Configurar Webhook URL no painel do Mercado Pago
  4. Obter Public Key (frontend) e Webhook Secret

12. Observações Finais

1. Sistema atual de doação continua: PIX manual ainda funcional
2. Compatibilidade reversa: doadores manuais existentes serão reconhecidos
3. Troféu Doador reaproveita função `marcarDoador()` já existente
4. Ao expirar o premium, usuário perde benefícios (mas mantém títulos comprados)
5. Mercado Pago oferece sandbox para testar sem dinheiro real
